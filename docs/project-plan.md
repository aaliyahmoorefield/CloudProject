# Project Plan

## Project Objective
The goal of this project is to design and implement a cloud-based smart parking system that allows students to view real time parking availability using Google Cloud Platform services.

## Sprint 1 (Initial Setup)
- Create GCP project
- Enable required APIs
- Set up VPC network and subnets
- Deploy Compute Engine instances
- Configure Cloud SQL or Firestore database
- Set up IAM roles and permissions

## Sprint 2 (Development)
- Implement data collection using Pub/Sub
- Process data using Cloud Functions
- Connect backend to database
- Develop basic user interface

## Sprint 3 (Testing & Security)
- Test system functionality
- Configure Cloud Logging and Monitoring
- Secure system using IAM and Secret Manager
- Fix bugs and improve performance

## Final Deliverables
- Working cloud-based parking system
- Architecture documentation
- GitHub repository with organized files
- Final report and presentation
